# Enterprise AI Chatbot for Customer Support 🤖

An intelligent, context-aware customer support chatbot built using Streamlit and Google Gemini LLM API[span_4](start_span)[span_4](end_span). This project features NLU, multi-turn conversation handling, real-time analytics, and voice integration[span_5](start_span)[span_5](end_span).

## 🌟 Features
* **Natural Language Understanding (NLU):** Handles queries in English, Urdu, and Roman Urdu[span_6](start_span)[span_6](end_span).
* **Context-Aware Responses:** Remembers conversation history for natural follow-ups[span_7](start_span)[span_7](end_span).
* **Real-Time Analytics:** Displays detected intent and confidence score dynamically in the sidebar[span_8](start_span)[span_8](end_span).
* **Voice Capabilities:** Includes Speech-to-Text input and Text-to-Speech audio generation[span_9](start_span)[span_9](end_span).
* **Smart Fallback Mechanism:** Ensures instant answers even if API calls encounter limits[span_10](start_span)[span_10](end_span).

## 🛠️ Tech Stack
* **Frontend:** Streamlit[span_11](start_span)[span_11](end_span)
* **AI Model:** Google Gemini API (`gemini-1.5-flash`)[span_12](start_span)[span_12](end_span)
* **Speech Processing:** `gTTS` (Text-to-Speech), `SpeechRecognition` (Speech-to-Text)[span_13](start_span)[span_13](end_span)
* **Language:** Python 3.10+[span_14](start_span)[span_14](end_span)
